# Game Timeline

*Runs 11:30 AM – 5:00 PM. Times are **start times** only. (IndyMods are run ad-hoc and do NOT go on this timeline.)*

*Two game runners — each mod needs either 1 or 2, and **every slot should have both runners in use.***

| Time | Event (game runners) |
|------|-------|
| **11:30** | **Setup** |
| **12:00** | **Game Start** |
| **12:30** | **He Said, She Said** (2)<br>*opens the game — 3 coins to the noble; the craftsperson's truth-telling ritual and herbs end up in play* |
| **1:00** | **The Rat Witch** (1)<br>*herbs, Clue 1, the Ritual of Banishment, potions — barter only, she won't take coin* |
| **1:00** | **Priest of the Old Gods** (1)<br>*the Ursgrom (Bear) artifact box, plus old god lore and how the binding works* |
| **1:30** | **Necromancer Attack** (2)<br>*whatever the necromancer carries — a few coins and an ingredient or two* |
| **1:30** | **First Shipment** (1)<br>*one box per merchant — herbs, Potion of Borrowed Dreams, Ritual of Binding / Box of Fish God, the cursed book; take each merchant's Grand Harbor order* |
| **2:00** | **The Play** (1)<br>*a purse of up to 20 coins for the best play — tales of things that really happened preferred* |
| **2:00** | **Beastmen Come to Town** (1)<br>*Clue 8, torn in half — traded for alcohol* |
| **2:30** | **Cups** (1)<br>*a Key, the Korrenvast (Iron) artifact box, Clue 7, a potion or two, a page of curses — one prize per win* |
| **3:00** | **Terrible Healing** (2)<br>*Valinfar's ritual, herbs from Melody's garden, and hush money if Valinfar is pressed* |
| **3:30** | **Second Shipment** (1)<br>*the merchants' Grand Harbor orders, plus herbs and any components that need to go out, for sale — Clue 6 at 3 coins* |
| **4:00** | **Ghost Invasion** (2)<br>*no loot — hands out curse cards; the reward is laying each spirit to rest* |
| **4:30** | **Falling Star** (2)<br>*the starmetal, and the final ritual (Asking the Gods)* |
| **4:45** | **EndGame** (2) |
| **5:00** | **Game End** |
