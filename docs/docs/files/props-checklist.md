# Props Checklist

*Master list of physical props needed to run the game. Whenever a new mod, character, or
doc specifies a physical prop, add it here.*

## Core Props

- [ ] **Coins** (silver pieces) — used throughout the game as currency.
- [ ] **Bones** — sacred bones can dissipate ghosts; also used as props/ingredients.

## Wristbands (monster station)

- [ ] **Blue wristbands** — Pro-Magic side (*Arguing Professors*); spares for players who pick a side.
- [ ] **Green wristbands** — Anti-Magic side (*Arguing Professors*); spares for players who pick a side.

## Headbands

- [ ] **White headbands** — mark a player as a ghost / spirit (*Ghost Invasion*, *Ghost Knight Fights*, ghost instructions).

## Mod-Specific

- [ ] **Chain** — binds the ghost to the necromancer (*Necromancer Attack*).
- [ ] **Starmetal** (fallen-star prop) — crashes to earth on cue; needed for the final ritual (*Falling Star*).

## Character-Specific

- [ ] **Deck of tarot cards** — the Astrologer's starting equipment.
- [ ] **Pile o' Post** — the Postperson's four folded letters to The Librarian (print from the *Pile o' Post* prop; contents listed in the *Setup* doc).

## Artifact Boxes (Gods)

- [ ] **Ursgrom (Bear) artifact box** — artifact item + Bear God page.
- [ ] **Uggglub (River) artifact box** — artifact item + **1 Vile Glomphidious** + River God page.
- [ ] **Korrenvast (Iron) artifact box** — artifact item + **5 coins** + Iron God page.

## Optional / Mod-Specific

- [ ] **Magic wedding ring** *(optional, 3D-printed)* — lays the Lover to rest (*Ghost Invasion*).
